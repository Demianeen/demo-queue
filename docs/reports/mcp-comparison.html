Why choose it?

  • Give an assistant read-only access.
  • View and disconnect connections in the app.
  • Optional keys and device approval for scripts.

What we would own

  • Our consent and settings pages.
  • Organization approvals and current membership enforcement.
  • Component credential state, configuration and upgrades.
  • A separate reviewed Production rollout.

Important limits

Select all means your current organizations. New memberships need a new approval. Losing membership removes access even while the credential remains valid.

The experiment now serves development MCP. Existing development clients need component reauthorization. Production clients keep WorkOS authorization.

WorkOS still receives membership checks on every tool call. There is no measured speed or price advantage.

The comparison branch intentionally cannot serve the component in Production. Its draft PR is for choosing the direction. A Production rollout needs separate authorization, configuration and verification.
What did review find and change?

The package cannot attach our organization selection directly to an OAuth grant. We use a server-owned approval ID, with atomic binding and owner checks, without forking the package.

Review caught an echoed device code and a manage-only read mismatch. Device approval now asks you to type the assistant's code. Management access consistently includes reads. Settings show the effective read-only permission when a client only requests reads. Argument parsing errors use safe structured responses.

The earlier public URL worker created an unwanted Vercel bypass token. It was removed and its absence verified. It supplied no verification evidence.

What remains outside this verification?
  • Component authorization in Production.
  • Successful external Google Sheet creation. AI success used an empty queue; Sheet sync verified enqueueing.
  • A second person's live Google sign-in and forced native refresh. These boundaries have automated two-owner and lifecycle coverage.
  • Production same-client multi-org consent. Its two verified connections use distinct registered clients.
  • Pagination beyond the latest 100 approval records, including revoked and pending rows. Add it before broad adoption.

Revocation cannot cancel a provider request already in flight. The final app write rechecks the local approval.
