# DevDay artwork provenance

OpenAI Sans and the character eye paths are reused from the existing DevDay Motion Studio assets, captured from the public DevDay recap character system. The paths retain their 55-unit optical wrappers, native widths and offsets. They are not font approximations. See `lib/devday-glyphs.ts` for source notes.

Theme layout, pointer interaction and wink timing are local interpretations based on the established Motion Studio direction, not an official OpenAI design specification. No generated raster artwork is used in the interface.
